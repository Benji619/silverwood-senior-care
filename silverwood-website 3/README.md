# 1st Silverwood Senior Care Home website

Approved green-and-cream design with 29 retouched photographs. The welcome card now shows the shared living room; the old steps photo was removed.

Unzip this archive. Upload the contents of the silverwood-website folder to your GitHub repository or static website host, keeping index.html at the root and preserving the assets folder. No build step is needed.

The contact form opens an email draft in the visitor’s email app; it does not send automatically.
