# 1st Silverwood Senior Care Home website

Updated November 23, 2026: polished illustrative caregiving hero; original home gallery and green design retained.

## GitHub and Netlify
Unzip this download. Upload the CONTENTS of the silverwood-website folder into the website folder in your GitHub repository. Keep index.html, styles.css, app.js, and assets beside each other.
Your existing GitHub website folder was named `silverwood-website 3`. If that remains your Netlify publish directory, replace its contents with these files. Commit to the production branch to trigger the connected Netlify deployment.
For manual deployment, drag the extracted silverwood-website folder onto the Deploys upload area of your existing Netlify project.

Contact form opens an email draft in the visitor's email application.
